# NLP Master Practitioner – 80 மணி நேர தமிழ் இணையப் பாடநெறி

## உள்ளடக்கம்
- 8 தொகுதிகள் × 5 பாடங்கள் = 40 பாடங்கள்.
- ஒவ்வொரு பாடத்திற்கும் 120 நிமிட **திட்டமிடப்பட்ட** கற்றல் செயல்பாடுகள்; மொத்தம் 80 மணி.
- தமிழ் விளக்கங்கள், வாழ்க்கைச் சூழல், ஆறு படிப் பயிற்சி, சுயபரிசோதனை, 2 கேள்வி மதிப்பீடு, பதிவிறக்கக்கூடிய TXT பணித்தாள்.
- மாணவர் பெயர், முன்னேற்றம், குறிப்புகள், பாடவாரி வீடியோ இணைப்பு அனைத்தும் browser localStorage-இல் மட்டுமே. இது உண்மையான login அல்லது பல சாதன ஒத்திசைவு அல்ல.
- வீடியோக்கள் சேர்க்கப்படவில்லை; உங்கள் சொந்த YouTube embed URL-களை மாணவர் உலாவியில் இணைக்கலாம். அனைவருக்கும் ஒரே வீடியோ காட்ட வேண்டுமானால் data/course.json / app.js-இல் மைய வீடியோ ஆதரவு சேர்க்க வேண்டும்.

## இணையத்தில் பதிவேற்றம்
1. ZIP கோப்பைப் பிரிக்கவும். `index.html`, `assets/`, `data/` ஆகியவற்றின் அமைப்பை மாற்ற வேண்டாம்.
2. Netlify Drop, GitHub Pages அல்லது HTTPS static hosting-இல் முழுக் கோப்புறையை பதிவேற்றவும்.
3. URL வழியாக திறந்து பெயர் உள்ளீடு, பாடம், வினாடி வினா, முன்னேற்றம், பணித்தாள் ஆகியவற்றைச் சோதிக்கவும்.
4. `index.html`-ஐ file:// முறையில் திறந்தால் JSON fetch இயங்காமல் இருக்கலாம். கணினியில் சோதிக்க `python -m http.server 8000` இயக்கி http://localhost:8000 திறக்கவும்.
5. மாணவர்களுக்கான உண்மையான கணக்குகள், Admin Editor, certificates, cloud progress ஆகியவை இந்தப் பதிப்பில் **இல்லை**. Supabase backend, RLS, admin roles, privacy policy ஆகியவை சேர்த்த பின்னரே அந்த வசதிகளை வழங்கவும்.

## பாட நேரம் பற்றிய நேர்மை
ஒவ்வொரு பாடத்திலும் வழிகாட்டப்பட்ட செயற்பாடுகளுக்கான 120 நிமிட திட்டம் உள்ளது. இது 80 மணி நேரப் பதிவுசெய்யப்பட்ட காணொளி உள்ளடக்கம் அல்ல; மாணவர் செலவிட்ட உண்மையான நேரத்தையும் கண்காணிக்காது. ஒவ்வொரு பாடமும் சுருக்கமான கருத்து விளக்கத்துடன் செய்முறை மையமாக வடிவமைக்கப்பட்டுள்ளது; முழுநீள விரிவுரை உரைகள் இல்லை.
